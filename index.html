NinjaOne Software Lookup

What it does

Live software inventory

Pulls directly from NinjaOne every time. Always reflects what's installed right now — never a cached snapshot.

Search by name or ID

Type a device name, hostname, or NinjaOne numeric ID. Recent searches stay one click away.

Filter & sort

Click any column to sort. Filter loaded software by name, publisher, or version. Hide first-party Microsoft components with one click.

Export anywhere

Save the visible list as CSV, or copy a formatted HTML table straight to your clipboard for ticket notes or documents.

How to use it

  1. 1

    Create a NinjaOne API app

    In NinjaOne, go to Administration → Apps → API → Add. Set Application Platform to API Services (machine-to-machine), Grant Type to Client Credentials, and add the monitoring scope. Save and copy the generated Client ID and Client Secret.

  2. 2

    Add your credentials to the app

    Click Settings in the top-right. Pick the NinjaOne region that matches your tenant, then paste the Client ID and Client Secret and click Save. Credentials are stored locally and never leave your machine.

  3. 3

    Search for a device

    Type a device name (full or partial), hostname, or NinjaOne numeric ID and press Enter. The device card up top shows its online status, plus the ID as a clickable badge that jumps straight to NinjaOne.

  4. 4

    Narrow down the results

    Sort by any column header. Use the Filter box to match by name, publisher, or version. Hit Hide Microsoft to suppress first-party Windows components and focus on user software.

  5. 5

    Export or paste

    Click Export CSV for a spreadsheet, or Copy as HTML to grab a formatted HTML table — paste it directly into a ticket note, email, or document and the table renders as-is.

Tips & shortcuts

  • Ctrl + K or / jumps to the search box from anywhere.
  • Esc clears the active filter or closes the recent-devices menu.
  • Click the clock icon in the search box for your last 10 devices.
  • Click the device ID badge to open the device page in NinjaOne.
  • Toggle the sun / moon icon for dark or light theme — it persists.
  • Refresh re-runs the last search without retyping.

Good to know

Credentials live in %APPDATA%\NinjaSoftwareLookup\config.json. They're preserved if you uninstall and reinstall — only the embedded browser profile is cleaned up.

Region matters: pick the NinjaOne endpoint that matches your tenant (US, EU, CA, OC). The wrong region returns 401 even with valid credentials.

Antivirus blocking? See TRUSTING-AV.md in the install folder for Trend Vision One and Defender allowlist instructions.
