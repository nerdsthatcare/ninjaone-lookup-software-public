What it does

Everything a technician needs to look up software on a NinjaOne device and hand that information off — without bouncing between NinjaOne's web UI and a ticket.

Search by name or ID

Type a hostname, display name, or NinjaOne device ID. The app resolves it against the NinjaOne API and pulls the device record.

Device info card

Organization, location, last contact, last logged-in user, online/offline status, plus a one-click deep link to open the device in NinjaOne.

Live filter & sort

Filter by name, publisher, or version. Sort any column. A "Hide Microsoft" toggle strips out first-party Windows components so third-party apps stand out.

Copy as HTML

One click produces a richly-formatted HTML table that pastes cleanly into ticket systems, email clients, or documents — defensive markup keeps it readable in both light and dark editor themes.

CSV export

Drop the visible result set straight to a spreadsheet — useful for audits, license reconciliation, or sending raw data to a vendor.

Recent devices

The last ten lookups stick around in a dropdown next to the search box, so re-checking a machine takes one click instead of retyping the name.

Light & dark themes

A liquid-glass interface that follows your OS preference, with brand-orange accents that tint the window title bar in app mode.

Keyboard-friendly

Search with CtrlK, jump to the filter with /, dismiss any dialog with Esc.

Credentials stored locally

API client ID and secret stay on your machine. The browser front-end never sees the secret — only the Go backend uses it to mint OAuth tokens.

How it works

A small Go binary serves a local web UI on a random port and embeds it in a Chrome app window. When the window closes, the Go process shuts down — no background services, no tray icons, nothing left running.

Type a device

Enter a hostname, display name, or numeric NinjaOne ID. Press Enter or click Search.

Auth & lookup

The backend exchanges your client credentials for an OAuth token, then queries NinjaOne for the matching device.

Pull software list

The device's installed-software inventory is fetched in a single API call and streamed back to the UI as JSON.

Filter & hand off

Apply filters or sort, then export to CSV or copy a formatted HTML table straight to a ticket, email, or document — both formatted for the destination.

Getting set up

The first time you launch the app it opens the Settings dialog and asks for your NinjaOne API credentials. After that, it remembers them.

1. Create an API app in NinjaOne

  1. Administration → Apps → API → Add
  2. Grant type: Client Credentials
  3. Scope: monitoring
  4. Save and copy the Client ID and Client Secret

2. Paste credentials

  • Pick your NinjaOne region (US, EU, CA, OC, US2)
  • Paste the Client ID and Client Secret
  • Click Save — credentials are stored locally only

3. Search away

  • Type any hostname, display name, or device ID
  • Use the device ID badge to deep-link into NinjaOne
  • Filter, sort, export to CSV, or copy as HTML
